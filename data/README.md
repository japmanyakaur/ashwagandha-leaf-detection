# Data

## `raw/ashwagandha/` (committed)

146 raw photos of potted Ashwagandha (*Withania somnifera*) plants — top-down shots
against soil/gravel/nursery-pot backgrounds, multiple leaves per image (whole
plant/branch shots, not isolated single leaves), varying plant maturity from sparse
4–6-leaf seedlings to dense bushy clusters. No boxes, no labels — pure source images.

Audit (originally run 2026-08-10 as a script, since converted to `notebooks/dataset_audit.ipynb` -- numbers below unchanged):

| Check | Result |
|---|---|
| Total images | 146 |
| Unique images (by MD5) | 140 |
| Exact duplicate pairs | 6 |
| Dimensions | 600×450px, uniformly |
| Corrupt files | 0 |

The uniform 600×450 size and three filename-ID clusters (118–130, 638–650, 2162–2281)
suggest this is a curated pull from a larger source collection rather than raw camera
dumps. The 6 duplicate pairs are **not deleted** — they're flagged in
`audit_report.json` (gitignored, regenerate with `notebooks/dataset_audit.ipynb`) so a
downstream step (e.g. `scripts/prepare_classifier_data.py`) can dedupe deliberately.
No competing plant species or weeds appear in-frame in this batch, so it doesn't yet
stress-test species discrimination against visually similar plants — worth sourcing
more varied negatives/hard-negatives later.

## `raw/negatives/<species>/` (not yet populated)

Needed for Stage 2 (Checker) training as the `not_ashwagandha` class. Plan: reuse
other-species images from the prior `leaf-localisation` project (PlantDoc, etc.).
Add one subfolder per species/source, e.g.:

```
data/raw/negatives/plantdoc/*.jpg
data/raw/negatives/soycotton/*.jpg
```

`scripts/prepare_classifier_data.py` flattens all subfolders into a single
`not_ashwagandha` class and will refuse to run (with a clear error) until at least
one image exists here.

## `detect/cvat_import.zip` (committed)

The Stage 1 box labels, after manual review. Flow: `scripts/auto_label.py` guesses
boxes with the old leaf-localisation model -> those get corrected by hand in CVAT ->
exported in "YOLO 1.1" format -> that export is this zip file. Unlike everything
below, this one isn't regeneratable (it's the actual human labeling work), so it's
committed rather than gitignored.

## Derived data (gitignored, regenerated by scripts)

- `detect/images/{train,val,test}/`, `detect/labels/{train,val,test}/`, `detect/data.yaml`
  — the actual training dataset, built from `cvat_import.zip` by `scripts/split_dataset.py`.
  `scripts/train_finder.py` consumes `detect/data.yaml`.
- `classify/` — Stage 2 classification dataset (`train/val` × `ashwagandha/not_ashwagandha`),
  built via `scripts/prepare_classifier_data.py`.
- `audit_report.json` — output of `notebooks/dataset_audit.ipynb`.
